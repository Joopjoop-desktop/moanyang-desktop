# 줍줍 기능 명세 (기획·디자인용)

개발 지식 없이 읽을 수 있도록, **지금 앱에 있는 기능과 사용 흐름**을 정리한 문서입니다. 화면 문구는 실제 앱에 나오는 글자 그대로 적었습니다.

- 기준: 개발 10단계 완료 시점 (MVP 진행 중)
- 개발 규칙·데이터 구조는 [`design.md`](design.md), 실행 방법은 [`development.md`](development.md)를 봅니다.
- **지금의 "AI 추출"은 진짜 AI가 아니라 정해진 규칙으로 글을 나누는 임시 방식입니다.** 실제 AI는 다음 단계(11단계)에서 붙습니다. 화면과 흐름은 그대로입니다.

---

## 1. 한 줄 요약

카톡·메일 등에 흩어진 메시지를 앱에 던져 넣으면(**먹이 주기**), 할 일·날짜·요청자를 뽑아 **캘린더에 자동으로** 넣어 준다. 정보가 빠진 것만 사람에게 "채워 주세요"라고 묻는다.

**핵심 원칙**

- 기본은 AI가 채우고, 사람은 **빠진 것만 채우거나 고친다**.
- 할 일과 날짜가 있으면 **사람 손을 거치지 않고** 캘린더에 들어간다.
- **메시지 원문은 저장하지 않는다.** 뽑아낸 결과(블록)만 남는다.

---

## 2. 용어

| 용어             | 뜻                                                                                         |
| ---------------- | ------------------------------------------------------------------------------------------ |
| 먹이 / 먹이 주기 | 앱에 넣는 메시지 글 / 글을 넣는 행동                                                       |
| 블록             | 일 하나를 담는 카드. 먹이 하나에서 블록이 여러 개 나올 수 있다                             |
| 요소             | 블록 안의 정보 한 줄. **할 일, 상세, 시작일, 마감일, 요청자, 메모** 6가지                  |
| 필수             | **할 일 + 날짜(시작일이나 마감일 중 하나)**. 둘 다 있어야 "다 된" 블록                     |
| 확인 필요        | AI가 날짜를 확신하지 못한 상태. 사람이 "확인"을 누르거나 고치면 풀린다                     |
| 채워 주세요      | 필수가 빠졌거나 날짜 확인이 필요한 블록 목록                                               |
| 날짜 없는 일     | 할 일은 있지만 날짜 없이 "이대로 두기"를 한 블록 목록                                      |
| 라벨             | 블록에 붙이는 상태 표시. 지금은 **조율 중**, **회신 대기** 두 가지(한 블록에 둘 중 하나만) |

## 3. 화면 구성

앱을 켜면 **스튜디오 창**과 **오늘 창**이 함께 뜨고, 작업표시줄 오른쪽 아래에 **트레이 아이콘**이 생긴다.

```
 스튜디오 창                                               오늘 창 (항상 위)
┌──────────────────────────────────────────────────┐   ┌────────────────┐
│ ① 먹이 칸(붙여넣기) · 실패 카드                  │   │ 오늘 10/10(토) ⚙ ▾│
├───────────────────────────────┬──────────────────┤   ├────────────────┤
│ ② 캘린더 (월간)               │ ③ 오른쪽 패널     │   │ ☐ 11:00 회의… 마감│
│                               │  채워 주세요 N   │   │ ☐ 분기 보고서 기간│
│                               │  날짜 없는 일 M  │   ├────────────────┤
└───────────────────────────────┴──────────────────┘   │ ▤ 서랍          │
                                                       └────────────────┘
```

| 화면          | 하는 일                                                                            |
| ------------- | ---------------------------------------------------------------------------------- |
| 스튜디오 창   | 일을 정리하는 메인 화면. ① 먹이 칸 ② 캘린더 ③ 오른쪽 패널(목록·블록 카드)          |
| 오늘 창       | 다른 앱 위에 항상 떠 있는 세로 창. 오늘 할 일 + 아래 서랍(먹이 받기)               |
| 트레이 아이콘 | 메뉴: **스튜디오 열기 / 오늘 창 숨기기(보이기) / 종료**. 왼쪽 클릭은 스튜디오 열기 |

**창 동작**

- 스튜디오 창의 X는 **숨기기**다. 앱은 트레이에 남아 계속 돈다. 진짜 끄기는 트레이 → 종료.
- 오늘 창도 Alt+F4 등으로 닫으면 숨기기다. 트레이에서 다시 보이게 한다.
- 앱은 하나만 실행된다. 이미 켜져 있는데 또 실행하면 기존 스튜디오가 앞으로 온다.

## 4. 먹이 주기

### 4.1 넣는 방법 3가지

| 방법                       | 어떻게                                                           |
| -------------------------- | ---------------------------------------------------------------- |
| 스튜디오 먹이 칸           | 맨 위 입력칸에 붙여넣고 **먹이 주기** 버튼 (또는 Ctrl+Enter)     |
| 오늘 창 서랍에 끌어다 놓기 | 다른 앱에서 글을 드래그로 골라 서랍 위에 놓는다                  |
| 오늘 창 서랍에 붙여넣기    | 서랍을 한 번 누르면 "Ctrl+V로 넣어 주세요"로 바뀌고, 그때 Ctrl+V |

- 오늘 창을 접어 둔 상태에서는 머리줄의 **"오늘 10/10(토)" 글자 부분**에 끌어다 놓으면 된다.
- 넣을 수 없는 경우
  - 빈 글: "먹일 글을 붙여넣어 주세요." (먹이 칸)
  - 20,000자 초과: "20,000자까지 먹일 수 있어요."
  - 파일·이미지: "글자만 넣을 수 있어요" (서랍)

### 4.2 넣은 뒤 흐름

1. 넣는 즉시 받아들인다. 스튜디오 먹이 칸이면 알림 "먹었어요! 정리하고 있어요.", 서랍은 **"정리하는 중…"**.
2. 뒤에서 할 일·날짜를 뽑는다. 여러 개를 연달아 넣어도 순서대로 처리한다.
3. 끝나면 결과가 바로 화면에 반영되고, 스튜디오 알림과 서랍(3초)에 결과가 뜬다.

| 결과                  | 문구                                                |
| --------------------- | --------------------------------------------------- |
| 모두 캘린더로 감      | 캘린더에 N개 넣었어요                               |
| 일부는 채워야 함      | 캘린더에 N개 넣었어요 / N개는 채워 주세요           |
| 모두 채워야 함        | N개는 채워 주세요                                   |
| 할 일이 아닌 글       | 할 일이 안 보여요 (블록이 생기지 않음)              |
| 실패 (다시 시도 가능) | 못 넣었어요. 스튜디오에서 다시 시도해 주세요 (서랍) |
| 실패 (다시 시도 불가) | 못 넣었어요 (서랍)                                  |

- 먹이가 끝나도 스튜디오를 저절로 띄우지 않는다. 서랍의 **"채워 주세요 N →"** 을 누르면 열린다.

### 4.3 실패와 다시 시도

- 네트워크 문제 등 일시적 실패는 **자동으로 3번 다시 시도**한다(2초 → 10초 → 30초 뒤). 그동안 서랍은 "정리하는 중…".
- 끝내 실패하면 스튜디오 먹이 칸 아래에 **실패 카드**가 생긴다.
  - "할 일을 뽑지 못했어요." + **다시 시도** / **닫기**
  - 다시 시도는 앱을 켜 둔 동안만 된다(원문을 저장하지 않으므로).
- 처리 중에 앱을 끄면 확인 창: "아직 처리 중인 먹이가 N개 있어요." / "지금 종료하면 처리하지 못한 먹이는 다시 먹여 주셔야 해요." → **종료 / 취소**
  - 그대로 종료하면 다음에 켰을 때 실패 카드 "처리하지 못했어요. 다시 먹여 주세요." (다시 시도 버튼 없음, 닫기만)

## 5. 블록 분류 — 어디에 나오나

뽑아낸 블록은 **요소를 보고 자동으로** 자리가 정해진다. 상태 버튼이 아니라 조건이라, 빠진 것을 채우면 저절로 옮겨 간다.

| 블록 상태                                 | 캘린더 | 채워 주세요    | 날짜 없는 일 |
| ----------------------------------------- | :----: | -------------- | :----------: |
| 할 일 + 날짜 있음                         |   ●    |                |              |
| 할 일 + 날짜 있음, 날짜 "확인 필요"       | ● 점선 | ● `날짜 확인`  |              |
| 할 일 있음, 날짜 없음                     |        | ● `날짜 없음`  |              |
| 할 일 있음, 날짜 없음, **이대로 두기** 함 |        |                |      ●       |
| 할 일 없음, 날짜 있음                     |   ●    | ● `할 일 없음` |              |
| 할 일 없음, 날짜 없음                     |        | ● `할 일 없음` |              |
| 완료한 블록                               | ● 흐림 |                |              |

- "날짜"는 시작일이나 마감일 중 하나라도 실제 날짜가 있으면 된다. "다음주쯤"처럼 날짜 없이 말만 있는 건 날짜로 치지 않는다.
- 하나에 여러 개가 빠지면 목록에는 **할 일 없음 → 날짜 없음 → 날짜 확인** 순서로 첫 번째만 표시한다.

### 빠진 것 채우는 방법

| 빠진 것    | 해결                                                     |
| ---------- | -------------------------------------------------------- |
| 할 일 없음 | "+ 추가 → 할 일"로 채우기, 또는 삭제                     |
| 날짜 없음  | "+ 추가 → 마감일(시작일)"로 채우기, 또는 **이대로 두기** |
| 날짜 확인  | 날짜 옆 **확인** 누르기, 또는 날짜 고치기                |

- "이대로 두기"는 **할 일이 있고 날짜만 없을 때만** 보인다. 누르면 "날짜 없는 일"로 옮겨 간다(알림의 되돌리기로 취소).
- 날짜 없는 일에 나중에 날짜를 넣으면 캘린더로 간다.

## 6. 스튜디오

### 6.1 캘린더

- 월간 보기. 일요일 시작, **‹ 지난달 / 오늘 / 다음달 ›** 버튼. 오늘 칸은 색으로 강조.
- 표시 방법

| 블록의 날짜      | 캘린더 표시                                                   |
| ---------------- | ------------------------------------------------------------- |
| 마감일만         | 그날 칸에 마감 표시(왼쪽 굵은 선)                             |
| 시작일만         | 그날 칸에 점                                                  |
| 시작일 + 마감일  | 시작~마감 **기간 막대**. 막대 위에도 시작 점·마감 표시가 남음 |
| 마감일이 여러 개 | 각 날짜에 모두 표시                                           |
| 시간이 있으면    | 제목 앞에 시간 (`11:00 견적서 송부`)                          |

- 항목 글자는 할 일. 할 일이 없으면 요청자 → 상세 → "(할 일 없음)".
- 완료한 일은 **흐리게 + 줄 긋기**, 날짜 확인 필요는 **점선 테두리**.
- 하루 칸에 3개까지 보이고 나머지는 **"+N개"**. 기간 막대도 3줄까지. 막대가 주를 넘으면 주마다 나눠 그린다.
- 항목을 누르면 오른쪽 패널에 그 블록 카드가 열린다. 날짜 칸의 빈 곳이나 "+N개"를 누르면 그날의 블록 목록이 열린다.
- 캘린더 위에서 끌어서 날짜를 바꾸는 기능은 없다(이후).

### 6.2 오른쪽 패널

항상 열려 있고, 기본은 목록이다.

**목록 (기본)**

- **채워 주세요 N** / **날짜 없는 일 M** 두 묶음. 최근에 넣은 것이 위.
- 한 줄 항목: `⠿ ▸ 제목 [빠진 것]`. 날짜 없는 일에는 빠진 것 표시가 없다.
- 줄을 누르면 그 자리에서 블록 카드가 펼쳐진다. 한 번에 하나만 펼쳐진다.
- 비어 있으면 "채울 블록이 없어요." / "날짜 없이 둔 일이 없어요."

**블록 카드 / 하루 목록** (캘린더에서 눌렀을 때)

- 위에 **← 목록** 버튼. 누르면 목록으로 돌아간다.
- 카드에서 **완료 체크**나 **삭제**를 하면 목록으로 돌아간다.
- 하루 목록이 비어 있으면 "이 날은 일정이 없어요."
- 오늘 창의 "스튜디오에서 열기"로도 이 화면이 열린다.

### 6.3 블록 카드

```
┌────────────────────────────────┐
│ ⠿ ☐ 10/10 09:12               │  손잡이 · 완료 체크 · 넣은 시각
│ [회신 대기 ×] [+ 라벨 ▾]       │  라벨
│ 할 일   견적서 송부        ×   │  요소 (누르면 고치기, 마우스 올리면 ×)
│ 마감일  10/20(화) 11:00        │
│         이번주 금요일까지 [확인 필요 | 확인] │
│ + 추가                         │
│ [이대로 두기]           [삭제] │
└────────────────────────────────┘
```

| 기능        | 동작                                                                                                                 |
| ----------- | -------------------------------------------------------------------------------------------------------------------- |
| 완료 체크   | ☐를 누르면 완료(알림 "완료했어요." + 되돌리기). 다시 누르면 완료 취소. 머리줄 시각이 "… 완료"로 바뀜                 |
| 요소 고치기 | 값을 누르면 그 자리에서 입력칸. 글자는 입력칸, 날짜는 날짜칸 + 시간칸. Enter 저장(여러 줄 칸은 Ctrl+Enter), Esc 취소 |
| 날짜 표시   | `10/9(금) 11:00`. 원래 메시지 표현("이번주 금요일까지")은 작게 함께. 올해가 아니면 연도를 붙임                       |
| 확인        | "확인 필요" 옆 **확인**을 누르면 값은 그대로 두고 확인 필요만 풀림                                                   |
| 요소 삭제   | 마우스를 올리면 ×. 누르면 삭제("요소를 삭제했어요."). **마지막 요소면 블록이 삭제**되고 되돌리기 알림                |
| + 추가      | 아래 6.4                                                                                                             |
| 라벨        | "+ 라벨"에서 고름. 붙은 라벨은 ×로 뗌. 조율 중·회신 대기는 한 블록에 하나만(다른 걸 붙이면 기존 것이 떨어짐)         |
| 이대로 두기 | 할 일 있고 날짜만 없을 때만 보임. "날짜 없는 일로 옮겼어요." + 되돌리기                                              |
| 삭제        | 화면에서 바로 사라지고 "삭제했어요." + 되돌리기. 휴지통 화면은 없다(되돌리기 알림이 유일한 복구)                     |

- 고치기에서 글자를 비우면 "비워둘 수 없어요. 지우려면 삭제해 주세요.", 날짜를 안 고르면 "날짜를 골라 주세요."

### 6.4 요소 추가 (+ 추가)

1. 카드 아래 **+ 추가**를 누른다.
2. 지금 추가할 수 있는 종류만 버튼으로 나온다.
   - **할 일·시작일·마감일·요청자**: 블록에 아직 없을 때만 나온다(있으면 그걸 고친다).
   - **상세·메모**: 항상 나온다.
3. 고르면 그 자리에 빈 입력칸이 열린다. 날짜 종류는 날짜(필수) + 시간(선택).
4. **추가**(또는 Enter)를 누르면 정해진 순서 자리에 들어간다: **할 일 → 상세 → 시작일 → 마감일 → 요청자 → 메모**.
5. 빈 채로 추가하면 아무것도 만들지 않고 닫힌다. Esc나 **취소**로 닫는다.

### 6.5 합치기 · 옮기기 · 나누기 (드래그)

오른쪽 **목록 패널 안에서만** 한다. 캘린더 쪽 카드는 끌 수 없다. 6px 이상 움직여야 끌기로 인식한다(짧게 누르면 클릭).

| 무엇을                | 어디에             | 결과                               |
| --------------------- | ------------------ | ---------------------------------- |
| 한 줄 항목의 손잡이 ⠿ | 다른 항목          | **합치기**: 두 블록이 하나로       |
| 펼친 카드의 요소      | 다른 항목          | **옮기기**: 그 블록 맨 뒤로        |
| 펼친 카드의 요소      | 목록 맨 아래 빈 칸 | **나누기**: 그 요소만 담은 새 블록 |
| 펼친 카드의 요소      | 같은 카드 안       | **순서 바꾸기**                    |

- 끄는 동안 놓을 수 있는 줄이 강조되고, 마우스를 따라 제목이 따라다닌다.
- 나누기 칸("여기에 놓으면 새 블록으로 나눠요")은 요소가 2개 이상인 블록의 요소를 끌 때만 보인다.
- 합치거나 옮겨서 블록이 비면 그 블록은 저절로 사라진다.

**겹칠 때 — 고르기 창**

할 일·시작일·마감일·요청자는 한 블록에 하나가 자연스러워서, 합치거나 옮길 때 같은 종류가 겹치면 남길 것을 고른다. 상세·메모는 겹쳐도 그냥 뒤에 붙는다.

1. 값이 **완전히 같으면** 묻지 않고 하나로 정리한다("값이 같은 요소 N개는 하나로 정리했어요.").
2. 값이 다르면 창이 뜬다: "블록 합치기(요소 옮기기): 겹치는 요소를 골라 주세요"
   - 종류별로 "원래 있던 것" / "옮겨오는 것"이 체크 목록으로 나온다. 처음에는 원래 있던 것에 체크되어 있다.
   - 여러 개를 함께 남길 수도 있다. 종류마다 **하나 이상** 골라야 **확인**이 켜진다.
   - **취소**하면 아무것도 바뀌지 않는다.
   - 그사이 다른 곳에서 내용이 바뀌었으면 "내용이 바뀌어서 다시 확인해 주세요."와 함께 다시 고르게 한다.
3. 합치기·옮기기는 되돌리기 알림이 없다.

### 6.6 알림 (화면 아래)

- 화면 아래 가운데에 최대 3개까지 쌓이고, 새 알림이 아래에 붙는다. 각각 5초 뒤 사라진다.
- 넘치면 버튼 없는 알림부터 빠진다. **되돌리기 알림은 다른 알림에 밀려 사라지지 않는다**(모두 되돌리기 알림이면 잠시 3개를 넘겨 보여 줌).
- 되돌리기가 있는 동작: 이대로 두기, 완료, 삭제.

## 7. 오늘 창

다른 앱 위에 항상 떠 있는 세로 창. 처음에는 화면 오른쪽 위에 뜬다.

### 7.1 머리줄

- **오늘 10/10(토)** — 빈 곳을 잡고 끌면 창이 움직인다.
- **⚙** — 아래에 투명도 슬라이더(30~100%, 기본 90%). 마우스를 올리면 100%로 진해진다.
- **▾ / ▸** — 접기·펼치기. 접으면 머리줄만 남고 안 끝낸 일 수가 배지로 보인다(`오늘 10/10(토) 3`).
- 위치·높이·투명도·접힘은 기억했다가 다음에 켤 때 그대로 띄운다.
- 창 아래·위 가장자리를 끌어 **세로 길이**를 바꿀 수 있다(폭은 고정).

### 7.2 오늘 할 일

- **오늘 칸에 보이는 일만** 나온다: 오늘 마감, 오늘 시작, 오늘을 지나가는 기간. **지난 마감은 나오지 않는다.**
- 줄: `☐ 11:00 회의실 예약 … 마감`
  - 시간: 오늘 날짜의 시작·마감 시간만 쓴다(여러 개면 가장 이른 것). 기간 중간 날에는 시간 없음.
  - 오른쪽 표시: 오늘 마감이 있으면 **마감**, 없고 오늘 시작이면 **시작**, 둘 다 없으면 **기간**.
- 순서: 시간 있는 일(시간 순) → 시간 없는 일 → 끝낸 일(줄 긋고 맨 아래).
- **☐ 체크**: 완료. 다시 누르면 풀린다(오늘 창에서는 되돌리기 알림 없음).
- **줄을 누르면** 요청자·상세·메모 등이 펼쳐진다(보기 전용, 한 번에 하나). 아래 **"스튜디오에서 열기 →"** 를 누르면 스튜디오가 앞으로 오고 오른쪽에 그 블록 카드가 열린다.
- 오늘 일이 없으면 "오늘은 할 일이 없어요."
- 자정이 지나면 1분 안에 새 날짜로 바뀐다.

### 7.3 서랍 (먹이 받기)

| 상태             | 서랍 모습·문구                                                    |
| ---------------- | ----------------------------------------------------------------- |
| 평소             | ▤ 끌어다 놓거나 눌러서 Ctrl+V                                     |
| 글을 끌고 옴     | 서랍이 열리듯 커지고 파랗게, "여기에 놓아 주세요"                 |
| 눌렀음           | 테두리 강조, "Ctrl+V로 넣어 주세요" (Esc나 다른 곳을 누르면 취소) |
| 처리 중          | 정리하는 중…                                                      |
| 끝남 (3초)       | 초록 글씨 "캘린더에 N개 넣었어요 / N개는 채워 주세요" (두 줄)     |
| 할 일 없음 (3초) | 할 일이 안 보여요                                                 |
| 실패·거절 (3초)  | 주황 글씨 "못 넣었어요. 스튜디오에서 다시 시도해 주세요" 등       |

- 채워 주세요가 1개 이상이면 아래에 **"채워 주세요 N →"**. 누르면 스튜디오가 열린다.
- 보여 주는 순서: 지금 하고 있는 일(끌기·붙여넣기) → 방금 끝난 결과 → 처리 중 → 평소 안내.

## 8. 주요 흐름 예시

> 아래 예시는 실제 AI가 붙은 뒤의 모습입니다. 지금 임시 추출에서는 "이번주 금요일까지" 같은 말을 날짜로 알아듣지 못해, `2026-10-16`처럼 숫자 날짜를 넣어야 같은 결과가 나옵니다([따라 해 보기](development.md#따라-해-보기)).

**A. 카톡 메시지 하나가 캘린더에 들어가기**

1. 카톡에서 "김과장: 견적서 이번주 금요일까지 보내주세요"를 드래그로 고른다.
2. 오늘 창 서랍에 놓는다 → 서랍 "정리하는 중…".
3. 할 일·날짜가 다 있으므로 바로 캘린더 금요일 칸에 들어간다.
4. 서랍 "캘린더에 1개 넣었어요". 금요일이 오늘이면 오늘 창 목록에도 생긴다.

**B. 날짜가 없는 메시지 채우기**

1. "회의실 예약 부탁드려요"를 넣는다 → 서랍 "1개는 채워 주세요", 서랍 아래 "채워 주세요 1 →".
2. 눌러서 스튜디오를 연다. 오른쪽 "채워 주세요"에 `▸ 회의실 예약 [날짜 없음]`.
3. 줄을 펼치고 **+ 추가 → 마감일**에서 날짜를 골라 추가한다.
4. 목록에서 사라지고 캘린더 그날 칸에 나타난다.
   - 날짜가 정말 없는 일이면 3단계에서 **이대로 두기** → "날짜 없는 일"로 이동.

**C. 쪼개져 들어온 메시지 합치기**

1. "견적서 보내주세요"와 "아 단가표도 같이요"가 따로 들어와 채워 주세요에 두 줄이 생겼다.
2. 아래 줄의 ⠿를 잡아 위 줄에 놓는다.
3. 할 일이 서로 다르면 고르기 창이 뜬다 → 남길 할 일을 고르고 확인.
4. 한 블록으로 합쳐진다.

**D. 오늘 일 처리하기**

1. 아침에 오늘 창에 오늘 할 일이 시간 순으로 보인다.
2. 끝낸 일의 ☐를 체크 → 줄이 그어지고 아래로 내려간다. 스튜디오 캘린더에서도 흐려진다.
3. 내용을 고쳐야 하면 줄을 펼쳐 "스튜디오에서 열기 →".
4. 일에 집중할 때는 ▾로 접어 두고, 그 상태에서도 글을 머리줄에 놓아 먹이를 줄 수 있다.
