# 맥 체험 빌드

M칩 맥용 설치 파일(.dmg)을 만들고 전달하는 방법, 설치 안내, 기본 동작 체크 목록입니다. (설계 3.2)

- 대상: M칩(M1~M4) 맥, macOS 12(Monterey) 이상. Intel 맥은 안 됩니다.
- 서명·공증이 없는 체험용입니다. 처음 한 번 경고를 없애는 명령이 필요합니다.
- AI 대신 가짜 추출기(Mock)가 동작합니다. 정해진 규칙대로 글을 나눕니다(아래 "써 볼 글").

---

## 1. 빌드하고 전달하기 (보내는 사람)

1. GitHub 저장소 → **Actions** 탭 → 왼쪽 **Build Mac**
2. 오른쪽 **Run workflow** → 브랜치 `develop` → **Run workflow**
3. 10분 정도 기다려 초록 체크가 뜨면 실행 기록을 누릅니다.
4. 아래 **Artifacts**의 `joopjoop-mac-arm64`를 내려받습니다(zip, 14일 보관).
5. zip을 풀면 `joopjoop-desktop-<버전>-arm64.dmg`가 나옵니다. 이 파일과 아래 "보낼 메시지"를 전달합니다.

> 실패(빨간 X)하면 실행 기록 → `build-mac` → 빨간 단계를 펼쳐 오류를 확인합니다.

### 보낼 메시지

```
줍줍 맥 체험판이에요. M칩 맥, macOS 12 이상에서 돌아가요.

1. dmg를 열고 Joopjoop을 Applications 폴더로 끌어 놓기
2. 터미널(Spotlight에서 "터미널")에 아래 한 줄 붙여넣고 Enter
   xattr -cr /Applications/Joopjoop.app
3. Applications에서 Joopjoop 열기

애플 서명이 없는 체험판이라 2번이 필요해요. 2번을 안 하면 "손상되었기 때문에 열 수 없습니다"가 떠요.
체크 목록은 같이 보낸 문서를 봐 주세요.
```

---

## 2. 설치하기 (받는 사람)

1. `.dmg`를 두 번 눌러 열고, **Joopjoop** 아이콘을 **Applications** 폴더로 끌어 놓습니다.
2. **터미널**을 엽니다(⌘ + Space → "터미널").
3. 아래 한 줄을 붙여넣고 Enter를 누릅니다. 아무 글자도 안 나오면 성공입니다.
   ```bash
   xattr -cr /Applications/Joopjoop.app
   ```
4. Applications 폴더에서 **Joopjoop**을 엽니다.

**그래도 안 열리면**

- "확인되지 않은 개발자" → 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 **그래도 열기**
- "손상되었기 때문에 열 수 없습니다" → 3번을 다시 합니다(앱을 Applications로 옮긴 뒤에 해야 합니다).

**새 버전으로 바꿀 때**: 메뉴 막대의 줍줍 아이콘 → 종료 → 새 dmg로 1~4번을 다시 합니다(덮어쓰기). 데이터는 그대로 남습니다.

**지우기**: 앱을 휴지통으로 옮깁니다. 데이터까지 지우려면 Finder → 이동 → 폴더로 이동(⌘ + ⇧ + G) → `~/Library/Application Support/Joopjoop` 폴더도 지웁니다.

## 3. 써 볼 글

스튜디오 맨 위 먹이 칸에 붙여넣고 **먹이 주기**를 누릅니다(또는 **Control + Enter**).
날짜는 꼭 `2026-10-20` 또는 `2026-10-20 11:00` 형식으로 씁니다. **오늘 날짜**로 쓰면 오늘 창에도 나옵니다.

**글 A**

```
견적서 송부 2026-10-20 11:00
단가표 첨부

회의실 예약
10명, 프로젝터 필요
```

**글 B**

```
[애매] 납품 일정 확인 2026-10-23
```

- 빈 줄로 나눈 덩어리 하나가 일 하나가 됩니다. 첫 줄이 할 일, 나머지는 상세입니다.
- 날짜가 있으면 캘린더로, 없으면 오른쪽 "채워 주세요"로 갑니다.
- `[애매]`가 있으면 그 글의 날짜가 모두 "확인 필요"가 됩니다. 그래서 따로 먹입니다.
- `[할일없음]`은 할 일이 아닌 글, `[실패]`는 실패한 경우를 볼 수 있습니다.

## 4. 기본 동작 체크 목록

안 되는 것이 있으면 번호와 화면 캡처(⌘ + ⇧ + 4)를 보내 주세요.

**켜기**

- [ ] 1. 앱을 열면 큰 창(스튜디오)과 화면 오른쪽 위의 작은 세로 창(오늘 창)이 뜬다
- [ ] 2. 위쪽 메뉴 막대에 줍줍 아이콘이 생긴다

**먹이 주기 (스튜디오)**

- [ ] 3. 글 A를 먹이 주기 → "캘린더에 1개 넣었어요. 1개는 채워 주세요." 알림
- [ ] 4. 캘린더 10월 20일에 `11:00 견적서 송부`, 오른쪽 "채워 주세요"에 `회의실 예약`
- [ ] 5. 글 B를 먹이 주기 → 캘린더 10월 23일에 점선 테두리 `납품 일정 확인`, "채워 주세요"에도 생긴다
- [ ] 6. `회의실 예약`을 펼쳐 "+ 추가 → 마감일"로 날짜를 넣으면 목록에서 빠지고 캘린더에 생긴다
- [ ] 7. 캘린더의 일을 누르면 오른쪽에 카드가 열리고, 글을 고칠 수 있다

**오늘 창**

- [ ] 8. 오늘 날짜로 먹이를 주면(예: `디자인 리뷰 <오늘 날짜>`) 오늘 창에 나온다
- [ ] 9. 체크박스를 누르면 줄이 그어지고 아래로 내려간다. 다시 누르면 풀린다
- [ ] 10. 머리줄을 끌면 창이 옮겨진다
- [ ] 11. 창 위·아래 가장자리를 끌면 세로 길이가 바뀐다 (폭은 그대로)
- [ ] 12. ⚙로 투명도를 바꿀 수 있고, 마우스를 올리면 진해진다
- [ ] 13. ▾로 접으면 머리줄만 남고, 다시 누르면 펼쳐진다
- [ ] 14. 다른 앱(메모 등)에서 글을 골라 서랍에 끌어다 놓으면 먹이가 된다
- [ ] 15. 서랍을 누르고 ⌘ + V 하면 복사한 글이 먹이가 된다 (화면에는 "Ctrl+V"로 적혀 있음)
- [ ] 16. 다른 앱을 눌러도 오늘 창은 계속 위에 떠 있다

**창 닫기·종료**

- [ ] 17. 스튜디오의 빨간 X를 누르면 창이 숨는다
- [ ] 18. Dock의 줍줍 아이콘을 누르면 스튜디오가 다시 뜬다
- [ ] 19. 메뉴 막대 아이콘 → "오늘 창 숨기기/보이기"가 동작한다
- [ ] 20. 메뉴 막대 아이콘 → 종료(또는 ⌘ + Q)로 앱이 꺼진다
- [ ] 21. 다시 열면 넣었던 일과 오늘 창 위치·높이·투명도가 그대로다

---

## 알고 있는 차이

- 화면 문구는 Windows 기준이라 "Ctrl+V", "Ctrl+Enter"로 적혀 있습니다. 맥에서는 붙여넣기는 ⌘ + V, 보내기는 **Control + Enter**입니다(⌘ + Enter는 아직 안 됩니다).
- 자동 업데이트가 없습니다. 새 버전은 dmg를 다시 받아 설치합니다.
